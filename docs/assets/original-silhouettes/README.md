# Silhouettes originales

30 illustrations SVG dessinées pour ce-dinosaure.fr, générées par
`scripts/draw_silhouettes.py`. Elles sont couvertes par la licence MIT du projet.
Elles ne proviennent pas du Natural History Museum. Le vert et les dimensions
reprennent le style des vignettes du catalogue.

Les silhouettes représentent des morphologies générales, avec quelques traits
caractéristiques. Elles ne sont pas des reconstitutions anatomiques scientifiques.
Les formes corporelles des dinosaures suivent les groupes indiqués par les
sources de leurs fiches ; les autres animaux utilisent des schémas originaux.
Les hybrides fictifs sont des interprétations stylisées.

Quand une longueur ou une envergure est documentée sur la fiche, l'humain original
mesure 1,75 m. Pour une fourchette, le dessin utilise son milieu. Les ptérosaures
sont vus de face, ailes ouvertes, pour comparer leur envergure à la taille humaine.
Sans mesure documentée, la vignette reste sans humain et sans échelle : aucune
nouvelle estimation de taille n'est introduite. Les infobulles et textes
alternatifs font cette distinction.

`manifest.json` associe chaque image à sa fiche, sans modifier le Markdown.
