# Silhouettes du Natural History Museum

© The Trustees of the Natural History Museum, London. Ces illustrations tierces
ne sont pas couvertes par la licence MIT du code du projet. Source et origine
de chaque fichier : `sources.json`. Extraction : 20 septembre 2026.

Les tracés SVG viennent des composants de comparaison du Dino Directory. Le
musée utilise des silhouettes génériques par forme corporelle, et non des
portraits propres à chaque genre. Les SVG locaux regroupent le dinosaure et
l'humain en conservant les proportions calculées par le composant du musée
(dont l'humain accroupi pour les petits animaux), avec un espacement de 8 unités.
La couleur a été adaptée au vert du site. Il s'agit d'illustrations schématiques.

Aucune comparaison n'est disponible dans le Dino Directory pour Brontosaurus.
Sa vignette reprend seulement le tracé générique de sauropode présent sur la
page Apatosaurus, sans humain et sans prétendre représenter une taille mesurée.
